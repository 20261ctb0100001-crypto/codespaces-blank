# Histórico de atividades

Materiais de aulas, exercícios e projetos anteriores do curso de Tecnologia da Informação.

## Organização

- `aulas/`: atividades separadas por aula.
- `estudos/`: materiais de revisão, estudos e rascunhos.
- `dados-antigos/`: arquivos de dados preservados de atividades anteriores.
- `configuracoes/`: configurações e arquivos de referência, incluindo o workflow antigo do Fliperama.

Os exercícios atuais do Beecrowd ficam em `../beecrowd/`, separados por linguagem (`C/` e `Python/`). O projeto atual do Fliperama fica em `../fliperama.c/`, incluindo seu código, dados, configurações e versões anteriores.

Esta pasta mantém materiais históricos e complementares; não é necessário mover os exercícios atuais para cá.
