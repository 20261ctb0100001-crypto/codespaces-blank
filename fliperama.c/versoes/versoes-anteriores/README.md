# Versões anteriores do Fliperama em C

Esta pasta guarda códigos de etapas anteriores do projeto.

- O projeto principal está em `../../fliperama.c`.
- Os arquivos em `versao-modular/` são uma versão antiga dividida em vários arquivos C.
- Os arquivos em `versoes-antigas/` são versões monolíticas anteriores.

Esses arquivos foram preservados para consulta e histórico. Eles não são necessários para compilar a versão principal atual. Para executar o projeto entregue, siga as instruções do `../../README.md`.
